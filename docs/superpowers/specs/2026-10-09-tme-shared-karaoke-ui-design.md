# TME 测试与内置打分共用演唱 UI

用户指定 TME 测试的歌词和打分 UI 与内置打分一致。

从 MainView 提取 KaraokePanelView，包含原 KaraokeView、GradeView、LineScoreView 和 IncentiveView。保留 KTV 背景、全宽 350pt 演唱区域、100pt 音高渲染高度、80pt 顶部预留空间，以及组件默认的白色正常歌词和粉色高亮歌词。累计分、句分动画与激励动画的布局沿用 MainView 原布局。

MainView 改为持有同一个面板，通过计算属性继续暴露原有组件，以保留既有内置打分的调用和参数设置。MainView 的按钮和调试区域保持现有布局。

TmeSingingVC 将共用面板放在 safe area 顶部，状态资料放在其下方可滚动区域，暂停按钮保留在底部。移除独立的文字句分/累计分以及浅色歌词覆盖，计分回调接入共用的分数和激励组件。音频播放、下载状态、失败提示、无计分降级、进度同步及麦克风逻辑保持原流程。

TME 的歌词拖动仍关闭，内置打分仍开启；这属于播放交互，不影响显示样式一致。没有有效计分模型时隐藏并收起整个共用面板的布局空间，避免显示无效分数，并确保状态/失败提示有显示空间。共用子视图保持固定 350pt 布局；准备成功后恢复面板高度并完成布局，再安装歌词模型。

验证 iOS demo 构建、现有 TME SDK 接线检查，并检查改动没有引入重复约束或影响 MainView 参数设置。
